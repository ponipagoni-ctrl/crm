# Два Telegram-бота

| Папка | Бот | По какому заданию |
|---|---|---|
| `fin_bot/` | **Финансовый консультант**: напоминания о платежах, днях рождения, страховке; учёт расходов; бюджет 50/30/20 | «Разработка чат-бота консультанта» |
| `mascot_bot/` | **Бот салона маникюра с маскотом Машей**: запись, подтверждение, напоминание, благодарность и оценка после визита | «Разработка персонажа (маскота) для бренда» |

## Как запустить (одинаково для обоих)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username (должен заканчиваться на `bot`) → скопируйте токен.
2. Установите Python 3.10+ и зависимости:
   ```bash
   cd fin_bot          # или mascot_bot
   pip install -r requirements.txt
   ```
3. Укажите токен и запустите:
   ```bash
   # macOS / Linux
   export BOT_TOKEN="123456:ABC..."
   python bot.py
   ```
   ```bat
   :: Windows
   set BOT_TOKEN=123456:ABC...
   python bot.py
   ```
   Или просто впишите токен в строку `BOT_TOKEN = ...` в начале `bot.py`.
4. Найдите своего бота в Telegram и нажмите **Start**.

Для каждого бота нужен **свой** токен (два разных бота в BotFather).

## Маскот-бот: картинки и админ

Положите в `mascot_bot/images/` картинки персонажа, сгенерированные в нейросети:

| Файл | Эмоция | Когда показывается |
|---|---|---|
| `hello.png` | машет рукой | приветствие /start |
| `booked.png` | с пилочкой и лаком | «Вы записаны на маникюр», напоминание накануне |
| `confirmed.png` | жест «ОК» | «Ваша запись подтверждена» |
| `thanks.png` | сложенные ладони | «Благодарим вас за визит» |
| `sad.png` | грустит | отмена записи |

Без картинок бот работает, просто присылает текст.

Чтобы получать заявки, задайте `ADMIN_ID` (свой id можно узнать у @userinfobot):
```bash
export ADMIN_ID=123456789
```
Команды администратора: `/visit N` — клиент получает благодарность и просьбу оценить; `/reply <id> текст` — ответить на вопрос клиента.

Название салона, адрес, телефон, услуги и цены меняются в начале `mascot_bot/bot.py`.

Данные хранятся в JSON-файлах рядом с ботом (`fin_data.json`, `bookings.json`). Бот должен быть запущен постоянно, чтобы присылать напоминания.
