# 🎉 MakeDay CRM

CRM-система для бизнеса праздников (Екатеринбург): ростовые куклы, Дед Мороз + Снегурочка, пенные вечеринки, выездная вата.

Работает и на компьютере, и на телефоне. Сделана по образцу лучших CRM (amoCRM): воронка сделок, карточки клиентов, календарь, напоминания о праздниках.

## Два режима работы

- **Локальный** (по умолчанию, пока `js/firebase-config.js` пуст): данные на устройстве, вход по коду доступа + паролю, шифрование AES-GCM.
- **Облачный** (после настройки Firebase — см. `SETUP-CLOUD.md`): общая база команды в Firestore с живой синхронизацией. Вход по email/паролю, новые сотрудники ждут одобрения администратора (Настройки → Команда), доступ уволенным закрывается одной кнопкой. Права проверяет сервер (`firestore.rules`).

## Вход и защита данных (локальный режим)

- Первый вход на устройстве: **код доступа** (выдаёт владелец) + свой пароль.
- Все данные CRM зашифрованы паролем (AES-GCM, ключ через PBKDF2 150k итераций) — без пароля их не прочитать даже через инструменты разработчика браузера.
- «Запомнить меня», смена пароля и блокировка — в Настройках.
- Код доступа хранится в коде только в виде SHA-256 хеша (`js/auth.js`), сам код в репозитории не фигурирует.

## Возможности

- **👥 Клиенты** — база с телефонами, адресами, тегами, заметками и историей заказов. Поиск и сортировка «по ближайшему празднику».
- **🎂 Даты праздников** — у каждого клиента можно указать любые даты (ДР ребёнка, юбилей, корпоратив). Повторяются каждый год, на главной — напоминания «через N дней».
- **💼 Сделки** — воронка как в amoCRM: Новая заявка → Переговоры → Предоплата → Подтверждён → Выполнен. Перетаскивание мышью или кнопками (на телефоне). Сумма, предоплата, адрес, время.
- **📅 Календарь** — все праздники клиентов и заказы на месяц.
- **📊 Главная** — сводка: ближайшие праздники, ближайшие заказы, выручка по месяцам.
- **✉️ Рассылка** — выбор получателей (все / у кого праздник в ближайшие 30–60 дней), готовые шаблоны с подстановкой {имя}, {праздник}, {дата}, отправка в WhatsApp или SMS в один тап по каждому клиенту, отметки «отправлено» и история рассылок.
- **📅 Импорт из Google Календаря (.ics)** — CRM понимает записи вида «Чебурашка 4500 Виталий 8953… девочке 9»: сама определяет услугу, цену, телефон, имя клиента и создаёт ежегодную дату праздника. Повторный импорт не создаёт дублей (по UID события).
- **📥 Импорт из Excel** — загрузите свои файлы `Клиенты.xlsx`, `База.xlsx`, `Рассылка.xlsx` в «Настройках»: колонки (имя, телефон, дата, адрес…) распознаются автоматически, повторные записи не дублируются.
- **💾 Резервная копия** — экспорт/импорт всех данных одним JSON-файлом, при импорте — режим «объединить» (без дублей) или «заменить».

## Как открыть

Это статический сайт — сервер не нужен.

- **Локально:** просто откройте `index.html` в браузере.
- **В интернете (рекомендуется):** перетащите папку проекта на [netlify.com/drop](https://app.netlify.com/drop) — получите ссылку вида `https://makeday-crm.netlify.app`, которая откроется с любого телефона. Точно так же уже размещён калькулятор `ded-moroz-ekb.netlify.app`.

## Где хранятся данные

В браузере (localStorage) того устройства, где вы работаете. Поэтому:

1. Работайте с CRM с одного основного устройства (например, телефона).
2. Раз в неделю: «Настройки → Скачать копию (JSON)».
3. Чтобы перенести на другое устройство: «Настройки → Восстановить из копии».

## Импорт ваших файлов с диска D:\

1. Откройте сайт на компьютере, где лежат файлы.
2. «Настройки → Выбрать файл Excel / CSV» → выберите `D:\Расылка\Клиенты.xlsx` (потом `База.xlsx` и `Рассылка.xlsx`).
3. Проверьте, что колонки распознаны правильно (можно поправить в выпадающих списках), и нажмите «Импортировать».

```

js/xlsx.full.min.js — библиотека SheetJS для чтения Excel (работает офлайн)
```
