# ☁️ Включение общей базы для команды (Firebase) — ~10 минут

После этой настройки все сотрудники будут видеть одну общую базу клиентов
и заказов с любого устройства, изменения появляются у всех мгновенно.
Бесплатного тарифа Firebase (Spark) хватает с огромным запасом.

## Шаг 1. Создать проект

1. Откройте https://console.firebase.google.com (войдите в Google-аккаунт **ponipagoni@gmail.com** — этот email будет администратором).
2. **Create a project** (Создать проект) → имя, например `makeday-crm` → Continue.
3. Google Analytics — выключите (не нужен) → Create project → дождитесь и нажмите Continue.

## Шаг 2. Включить вход по email

1. В меню слева: **Build → Authentication** → **Get started**.
2. Вкладка **Sign-in method** → **Email/Password** → включите верхний переключатель → **Save**.

## Шаг 3. Создать базу данных

1. В меню слева: **Build → Firestore Database** → **Create database**.
2. Location: выберите **europe-west1** (или любой europe) → Next.
3. Режим: **Start in production mode** → Create.
4. Откройте вкладку **Rules**, удалите всё и вставьте содержимое файла `firestore.rules` из этого репозитория → **Publish**.

## Шаг 4. Получить конфигурацию

1. Шестерёнка вверху слева → **Project settings**.
2. Вкладка **General**, внизу раздел **Your apps** → нажмите значок **`</>`** (Web).
3. Nickname: `crm` → **Register app** (Firebase Hosting не включать).
4. Появится код с `const firebaseConfig = { apiKey: "...", ... }` —
   **скопируйте всё, что внутри фигурных скобок**, и отправьте Claude в чат.

## Шаг 5. Готово

Claude вставит конфигурацию в `js/firebase-config.js` и отправит на GitHub —
через минуту сайт переключится в облачный режим:

- Вы входите под **ponipagoni@gmail.com** (первый раз — «Регистрация») — это админ.
- Сотрудник открывает ту же ссылку → «Регистрация» → ждёт, пока вы
  одобрите его в **Настройки → Команда**.
- Старую базу перенесите так: Настройки → Восстановить из копии →
  выберите ваш JSON (например `klienty-iz-kalendarya.json`) → «Объединить».

## Если сотрудник уволился

Настройки → Команда → «Отключить» — доступ закрывается сразу на всех его устройствах.
